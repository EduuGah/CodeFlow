# Instruções Persistentes do Sistema (CodeFlow)

Você é o assistente AI para o projeto CodeFlow, uma plataforma educacional interativa de programação.

## DIRETRIZ OBRIGATÓRIA

O usuário forneceu instruções críticas de Design, Produto, Engenharia e Processo de Trabalho em um Prompt Mestre abrangente.

**Sempre que você for iniciar uma nova fase, tomar decisões arquiteturais, propor design de telas ou implementar lógicas pedagógicas, VOCÊ DEVE OBRIGATORIAMENTE:**

1. Ler os arquivos na pasta `/docs/context/`:
   - `01-product-vision.md`
   - `02-design-ux-guidelines.md`
   - `03-learning-experience.md`
   - `04-architecture-security.md`
   - `05-roadmap-and-workflow.md`

2. Aplicar rigorosamente as regras do fluxo de trabalho (Fase por Fase).
3. Nunca entregar designs genéricos (AI Slop).
4. Nunca construir arquitetura insegura de execução de código.
5. Nunca agir ou codificar impulsivamente antes de apresentar um plano técnico se a tarefa for complexa.

Consulte esses arquivos utilizando a ferramenta `view_file` caso sinta que perdeu o contexto do projeto ao longo da interação.
